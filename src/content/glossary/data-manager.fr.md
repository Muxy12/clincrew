Le data manager (gestionnaire de données cliniques) conçoit et gère la base de données d'un essai clinique. Il garantit que les données recueillies sont complètes, cohérentes et exploitables pour l'analyse. Il travaille en lien étroit avec les ARC et les biostatisticiens.

## Ce que fait un data manager

- Concevoir le cahier d'observation électronique (eCRF) et la base EDC
- Émettre et suivre les queries (demandes de correction)
- Contrôler la cohérence et la qualité des données avant le gel de la base

## Data manager et monitoring

Le data manager et l'ARC se complètent : l'ARC vérifie les données sur le terrain, notamment par la [vérification des données source (SDV)](/fr/glossaire/sdv) ; le data manager les contrôle à distance et pilote les queries. Ensemble, ils protègent la qualité des données.

*Référence : recherche clinique, gestion des données.*
