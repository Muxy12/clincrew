The clinical data manager designs and runs a clinical trial's database. They ensure the data collected is complete, consistent and usable for analysis. They work closely with CRAs and biostatisticians.

## What a data manager does

- Design the electronic case report form (eCRF) and the EDC database
- Raise and track queries (correction requests)
- Check the consistency and quality of data before database lock

## Data manager and monitoring

The data manager and the CRA complement each other: the CRA verifies data in the field, notably through [source data verification (SDV)](/en/glossaire/sdv); the data manager checks it remotely and drives the queries. Together, they protect data quality.
