Le CRF (Case Report Form), ou cahier d'observation, est le document dans lequel sont recueillies les données de chaque participant à un essai clinique, telles que prévues par le protocole. Aujourd'hui, il est le plus souvent électronique : on parle alors d'eCRF.

## À quoi sert le cahier d'observation

Le CRF structure le recueil des données : pour chaque visite, il définit quelles informations noter (critères d'évaluation, événements indésirables, traitements…). C'est la matière première de l'analyse statistique de l'étude.

## Du papier à l'électronique (eCRF)

L'eCRF, intégré à un système EDC (Electronic Data Capture), a largement remplacé le papier. Il apporte des contrôles de cohérence automatiques, un accès à distance et une traçabilité renforcée. Il facilite aussi la gestion des [queries](/fr/blog/queries-recherche-clinique).

## Le rôle de l'ARC

L'ARC ne saisit pas les données (c'est le rôle du centre), mais il les vérifie. Lors du monitoring, il contrôle la concordance entre le cahier d'observation et les documents sources : c'est la [vérification des données source (SDV)](/fr/glossaire/sdv). Toute incohérence déclenche une query.

## eCRF, EDC, CTMS, eTMF

Le cahier d'observation s'inscrit dans un écosystème d'outils : l'eCRF/EDC pour les données, le [CTMS](/fr/blog/ctms-recherche-clinique) pour piloter l'étude, l'eTMF pour la documentation. Le [data manager](/fr/glossaire/data-manager) en est le garant côté données.
